# /runlog is now /run-log

> **When to use**: never. Run `/run-log` instead.

Toolkit v2.2.0 renamed this command to `/run-log`. Tell the user so in one line, give them the exact command to run
(`/run-log $ARGUMENTS`), and stop. Do not run the old procedure from memory. This pointer is removed in the release
after v2.2.0.
