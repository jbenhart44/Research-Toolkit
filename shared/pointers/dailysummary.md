# /dailysummary is now /daily-summary

> **When to use**: never. Run `/daily-summary` instead.

Toolkit v2.2.0 renamed this command to `/daily-summary`. Tell the user so in one line, give them the exact command to
run (`/daily-summary $ARGUMENTS`), and stop. Do not run the old procedure from memory. This pointer is removed in the
release after v2.2.0.
